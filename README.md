# 夜鹭天屎

一个以真实夜鹭行为为灵感的水彩互动小工具。游戏里的夜鹭叫“夜师傅”。

当前阶段：**M0 核心动画 Demo**。

M0 只验证一次点击后的核心动作：投喂小鱼 → 夜师傅捕食吞咽 → 原地“天屎降临” → 涟漪 → 若无其事恢复。完整概率、鸟运、图鉴和分享暂不实现。

开发前请先阅读：
- `SKILL.md`
- `docs/M0-ACCEPTANCE.md`

## M0 启动目标
保持零/低依赖。优先做到直接打开 `index.html` 即可运行；如浏览器限制本地资源，可用任意静态 HTTP server 启动仓库根目录。

## 视觉原则
清新自然的水彩观察手帐；背景淡，夜师傅清晰；真实夜鹭比例，不做 Q 版手游化。
