# 夜鹭天屎

一个以真实夜鹭行为为灵感的水彩互动小工具。游戏里的夜鹭叫“夜师傅”。

当前阶段：**M0 核心动画 Demo**。

M0 只验证一次点击后的核心动作：投喂小鱼 → 夜师傅捕食吞咽 → 原地“天屎降临” → 涟漪 → 若无其事恢复。完整概率、鸟运、图鉴和分享暂不实现。

开发前请先阅读：
- `SKILL.md`
- `docs/M0-ACCEPTANCE.md`

## 启动方式

本项目没有构建步骤，也没有运行时外部依赖。

1. 直接用 Chrome 或 Edge 打开仓库根目录的 `index.html`。
2. 或在仓库根目录启动任意静态服务器，例如：

   ```bash
   python3 -m http.server 4173 --bind 0.0.0.0
   ```

建议用浏览器开发者工具的 `390 × 844` 手机竖屏尺寸体验，点击画面正下方的竹编鱼篓开始投喂。

安装锁定的浏览器测试依赖并运行全部自动检查：

```bash
npm ci
npx playwright install chromium
npm run check
```

其中 `npm test` 运行可复现的状态机、首次提示、声音反馈和资产接口单元测试；`npm run test:browser` 会自行启动临时静态服务器，并使用 Playwright Chromium 检查 390×844 页面、直接打开 `index.html`、localStorage 跨刷新、固定随机分支、声音事件、输入锁和控制台异常。GitHub Actions 会在 PR 与 `main` 推送时执行同一套检查。

## 视觉原则
清新自然的水彩观察手帐；背景淡，夜师傅清晰；真实夜鹭比例，不做 Q 版手游化。

## 状态

Issue #1 的 M0 核心动画 Demo 已实现。动画由 `requestAnimationFrame` 和明确状态机驱动；配置、状态逻辑、角色、鱼和特效绘制相互分离。

## M0 范围

仅包含一次点击后的核心动作：抛鱼、三落点随机、跟踪捕食、两种叼鱼表现、吞咽“咕。”反馈、吞咽变圆、强制“天屎降临”、落水“啪嗒。”反馈、涟漪和恢复待机。声音使用浏览器 Web Audio 本地合成，不加载外部音频资源；浏览器不支持或阻止音频时，视觉流程仍可完整运行。

首次“点击投喂”提示在成功投喂后通过 `yelu:m0:feed-hint-dismissed:v1` 保存，刷新后不再显示；localStorage 不可用时降级为当前页面会话内隐藏。

概率、8 条鱼完整循环、随机安全动作、鸟运签、捞签、图鉴、分享、小红书 API 和水门礼均未实现，留待 M1 以后。

## 已知限制

- 当前正式美术资源尚未拆成透明图层，夜师傅、背景和特效明确使用 `m0-canvas-placeholder` Canvas 水彩占位资产包，并非正式角色设计。`SceneRenderer` 通过 asset pack 接口消费背景、夜师傅、鱼、鱼篓和特效绘制器；后续正式透明素材可替换同一接口，无需改写状态机。
- M0 以现代 Chrome/Edge 和约 `390 × 844` 竖屏为主要目标，未针对旧版浏览器做兼容处理。
